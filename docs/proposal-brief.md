## 0. 铁律第 0 条：不录译文

底本是**草婴译本**（读客经典文库 / 江苏凤凰文艺 2019），**仍在版权保护期内**。

**禁止**：
1. 复制、改写、搬运底本或读客版《各章内容梳理》的任何**措辞**；
2. `gist` 中出现引号包裹且长度 > 20 字的片段（lint 硬拦）；
3. `gist` 中出现原文对话、独白、叙述句的连续复述。

**要求**：`gist` 是你**自己写的**情节概述——用你自己的措辞说清「这一章发生了什么」。
情节事实不受版权保护，表达受保护。读正文是为了知道发生了什么，不是为了抄句子。

`corpus/appendix-outline.txt`（读客版增补的《各章内容梳理》）**只允许用于定位与核对**，
**绝不可**照抄或改写成你的输出。若你不确定某章内容，读 `corpus/ch/<id>.txt` 正文。

## 1. 你的产物

一个 Python 文件，例如负责 `1-1` 部就写 `data/proposals/notes_1-1.py`：

```python
# -*- coding: utf-8 -*-
NOTES = {
    "1-1-01": {"gist": "…", "tag": "salon", "place": "彼得堡",
               "chars": ["anna_sherer", "vasily"], "year": 1805, "month": 7},
    "1-1-02": {"gist": "…", "tag": "salon", "chars": ["pierre", "anna_sherer"]},
    # … 本部每一章一条，不许跳号
}
```

- 文件**必须以 `NOTES = {` 开头**（可加注释行），可被 `importlib` 直接导入；
- key 必须与 `corpus/ch/` 的文件名完全一致（如 `"1-1-01"`，两位数补零）；
- **你负责的部的每一章都要有一条**，一章不能少。

## 2. 字段规范

| 字段 | 必填 | 说明 |
|---|---|---|
| `gist` | ✅ | 自撰概述，**≤60 字**（含标点，汉字计数）。这是唯一必需的字段 |
| `tag` | ✅ | 受控值之一：`peace`（和平/家庭/社交）、`war`（战争/行军/战场）、`essay`（史论议论章）、`transition`（过场/转场） |
| `chars` | 建议 | 该章**实际出场**的人物 id 数组（见 §3）。只用表内 id。宁少勿滥：只列真正有戏份的 |
| `place` | 建议 | 该章主场景地点，必须是 `data/places.js` 中的键（见 §4）。纯议论章可省略 |
| `year` | 建议 | 故事内年份（整数）。正文明确写出时才填，**不要推测** |
| `month` | 可选 | 1–12。同样只在正文明确时填 |

**不要填**：`event`、`flag`、任何其他字段。章节与事件的关联只在 `EVENTS[].ch` 维护，前端据此建立反向索引，不再维护章节卡的单一 `event` 字段。

### 关于 `gist` 的写法

- 60 字要放最有信息量的东西：**谁 + 在哪 + 发生了什么 + 这一章的分量**；
- 写"安德烈在奥斯特里茨扛旗冲锋后倒地仰望天空"，不写"这一章描写了战争"；
- 不要写"本章讲述了…"这类空话开头的套路，直接讲事；
- 议论章（`tag:"essay"`）写清托尔斯泰在论什么，例如"史论：驳「天才指挥战争」之说，主张胜负由无数偶然与士兵意志决定"；
- 第三人称客观陈述，不加评论、不加"精彩""深刻"之类评价。

## 4.5 查人名时的**硬性工具要求**

核查某人是否在某章**正面出场**，**禁止**用 `grep -o '.\{0,40\}名字.\{0,80\}'`。

原因（已实测复现）：grep 的 `.` 按**字节**计数，汉字占 3 字节，40 字节窗口只容约 13 字；
窗口边界切在半个字符上时**整条命中被丢弃**——前缀有 5..45 个汉字时 `grep -o` 会**全部返回空**，
而 `grep -c` 计数仍正常。误信空输出就会把「正面出场」误判成「仅被提及」。

**必须改用**：

```bash
python3 scripts/ctx.py <人名>              # 全书上下文，按句切分并标注[出场]/[提及]
python3 scripts/ctx.py <人名> 3-2-25       # 只看某章
python3 scripts/ctx.py <人名> --chapters   # 只列出现的章
python3 scripts/ctx.py <人名> --present    # 只列疑似正面出场
```

该脚本按**句**切分后判定，不受定长窗口影响，输出 `[出场]/[转述]/[提及]` 三档，
但**最终仍须人读原文判定**。

**「出场」的统一定义**：本人在该场景中**有在场行动或对白**，含静态在场
（如「薇拉和申兴在客厅里下棋」）。**转述旧话、书信问候、他人谈论其心情、
宅邸/地名/团体名、注脚与史论点名，均不算出场。**

凡 `grep -c` 的章数多于你肉眼看到的命中条数时，一律换 `ctx.py` 复核。

## 5. 工作方法

1. 对每一章：`read corpus/ch/<你的部>-<章>.txt`（文件不大，可整读）；
2. 读完后**合上原文**，用你自己的话写下 `gist`；
3. 判断 `tag`、挑出真正出场的人物、确认地点与年份（正文明确写出才填）；
4. 写作时字数控制：写完数一下，超过 60 字就砍掉次要信息；
5. 全部写完，`write` 出提案文件。

**不要**：跑 lint、跑测试、跑格式化、提交 git。只产出提案文件一件事。
